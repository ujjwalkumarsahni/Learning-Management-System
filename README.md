# 📚 Full-Stack Learning Management System (LMS)

A feature-rich, full-stack Learning Management System (LMS) that enables administrators, instructors, and students to interact in a digital learning environment. Includes secure authentication, course and lesson management, assignment submissions, and detailed performance analytics.

## 🔗 Live Demo

[🌐 Live Site](https://lms-frontend-rosy-seven.vercel.app/)


## 🚀 Features

- ✅ **Role-Based Access**: Admin, Instructor, Student
- 🧑‍🏫 **Instructor Tools**: Create/manage courses, upload lessons, assign tasks
- 🧑‍🎓 **Student Tools**: Enroll in courses, submit assignments, view progress
- 📊 **Admin Dashboard**: User management, analytics, and course oversight
- 📂 **Assignment Uploads** with file handling
- 🧠 **Performance Tracking** via dynamic dashboards
- 🔒 **JWT Authentication** for secure login sessions
- 📱 **Responsive Design** using TailwindCSS
